# 步骤间复查清单 (Inter-Step Review Checklist)

> Agent G（关卡Agent）在每个审稿人产出后执行的复查清单。确保每个审稿人的输出质量在进入下一阶段前达标。

---

## 复查时机

```
Agent R1 产出 ──→ [Agent G 复查] ──→ 通过/打回
Agent R2 产出 ──→ [Agent G 复查] ──→ 通过/打回
...
Agent R6 产出 ──→ [Agent G 复查] ──→ 通过/打回
                        │
                        ▼
              [Agent G 交叉复查]
                        │
                        ▼
                  Agent M 主编综合
```

---

## 单个审稿人复查清单

### Part 1: 维度覆盖检查

对照 `harness/reviewer-profiles.md` 中各审稿人的检查维度：

**R1 方法学审稿人的维度覆盖**:
```
□ M1. 综述类型一致性       → 报告中有对应章节？
□ M2. 检索方法充分性       → 报告中有对应章节？
□ M3. 纳入/排除标准        → 报告中有对应章节？
□ M4. 偏倚风险评估         → 报告中有对应章节？
□ M5. 证据等级             → 报告中有对应章节？
□ M6. 可复现性             → 报告中有对应章节？
```

**R2 临床审稿人的维度覆盖**: C1-C5
**R3 逻辑审稿人的维度覆盖**: L1-L5
**R4 统计审稿人的维度覆盖**: S1-S5
**R5 文献覆盖审稿人的维度覆盖**: LC1-LC5
**R6 结构审稿人的维度覆盖**: N1-N5

**通过标准**: ≥5/6（或≥4/5）维度被覆盖

### Part 2: 发现质量检查

| 检查项 | 方法 | 标准 |
|--------|------|------|
| 位置标注 | 每条发现是否有"§X.Y ¶N"位置标注？ | 100% |
| 原文引用 | 每条发现是否引用了稿件原文？ | 100% |
| 严重性分级 | Critical/Major/Minor/Suggestion 分级是否合理？ | 抽查3条 |
| 改进建议 | 每条发现是否有具体改进建议？ | 100% |
| 评分完整性 | 是否给出了维度评分和综合评分？ | 100% |

### Part 3: 独立性检查

| 检查项 | 方法 | 标准 |
|--------|------|------|
| 跨审稿人引用 | 搜索"根据R1""如R3所述"等字样 | 0 出现 |
| 风格一致性 | 审稿报告是否使用该审稿人的专业语言风格？ | 风格匹配 |
| 角色漂移 | 审稿人是否越界评价非其领域的问题？ | 无越界 |

### Part 4: 综合判定

```
所有Part 1-3通过 → ✅ 通过，报告进入主编综合队列
Part 1不通过     → 🔄 打回补充：具体要求补充哪些维度
Part 2不通过     → 🔄 打回修正：具体要求修正哪类问题
Part 3不通过     → ⚠️ 标记异常：在主编综合中标注该审稿报告可能受污染
```

## 交叉复查清单（所有审稿人通过后）

### 审稿报告间矛盾检测

```
□ 扫描各审稿报告中对同一文本位置的评价
□ 如果 R2 说"临床讨论充分"，R3 说"该段缺乏论证深度" → 标记矛盾
□ 矛盾类型: 事实矛盾 / 评价矛盾 / 严重性矛盾
□ 事实矛盾 → 需人工判断 → 在主编综合中标注
□ 评价矛盾 → 保留双方意见 → 主编综合时决定权重
□ 严重性矛盾 → 取更严重的分级（宁严勿松）
```

### 重复发现去重

```
□ 扫描不同审稿人是否发现了同一问题
□ 去重规则:
  - 同一文本位置 + 同一问题类型 → 合并为一条，标注"R2,R3共同发现"
  - 同一问题类型 + 不同文本位置 → 保留为独立发现
  - 同一文本位置 + 不同问题类型 → 保留为独立发现
```

### 覆盖盲区检测

```
□ 是否有稿件章节没有任何审稿人指出问题？
  → 检查是该章节确实完美，还是审稿人都忽略了
□ 是否有常见的AI写作缺陷未被任何审稿人发现？
  → 对照 knowledge/common-ai-defects.md 交叉检查
```

## 复查输出

Agent G 每次复查后生成一个复查报告卡片：

```markdown
## 复查报告 — R1 方法学审稿人

### 复查结果: ✅ 通过

### 维度覆盖
- M1 ✅ M2 ✅ M3 ✅ M4 ⚠️(简略但覆盖) M5 ✅ M6 ✅
- 覆盖率: 6/6

### 发现质量
- 总发现: 8条 (Critical 2, Major 3, Minor 3)
- 位置标注: 8/8 ✅
- 改进建议: 8/8 ✅
- 抽查验证: 3/3 位置准确 + 分级合理

### 独立性
- 无跨审稿人引用 ✅
- 风格正确 ✅
- 无越界评价 ✅

### 备注
- M4偏倚评估的讨论较简略，但已覆盖关键点，可以通过
```
