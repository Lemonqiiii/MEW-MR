# 质量关卡系统 — 审稿项目 (Quality Gate System)

> 审稿项目的每个 Phase 输出在进入下一 Phase 之前，必须通过质量关卡检查。未经检查的输出 = 未完成。

---

## 审稿专用八道关卡 (GA1-GA8)

### Gate GA1: 稿件接收 → 预处理

| 检查项 | 方法 | 通过标准 |
|--------|------|---------|
| 稿件格式完整性 | 检查文件是否可解析、编码是否正确 | 无乱码、无缺失段落 |
| 引用格式一致性 | 检查引用编号是否连续、格式是否统一 | 编号无跳跃、格式统一 |
| 必要元数据 | 检查标题/作者/摘要/正文/引用 五部分是否齐全 | 5/5 齐全 |
| Disclosure Packet 完整性 | 检查6类信息是否齐全 | 6/6 信息类别覆盖 |

### Gate GA2: 预处理 → 分发审稿

| 检查项 | 方法 | 通过标准 |
|--------|------|---------|
| 知情包构建 | 验证 Disclosure Packet 仅含6类允许信息 | 0 超标信息 |
| 屏蔽清单验证 | 逐项确认屏蔽信息不可被审稿Agent访问 | 100% 屏蔽 |
| 稿件分节 | 确认章节边界标注正确 | 标注与原文一致 |
| 审稿人任务分配 | 每个审稿人的prompt中仅包含该维度检查清单 | 无跨维度污染 |

### Gate GA3: 各审稿人产出 → 关卡复查

| 检查项 | 方法 | 通过标准 |
|--------|------|---------|
| 维度覆盖完整性 | 对照各审稿人的检查维度清单逐项核验 | ≥90% 维度覆盖 |
| 问题定位准确性 | 随机抽3条发现，验证章节/段落标注是否正确 | 3/3 准确 |
| 严重性分级合理性 | 检查 Critical/Major/Minor 的分级逻辑 | 无明显的错级 |
| 改进建议可操作性 | 每条批评是否附带具体可执行的改进建议 | 100% 附带 |
| 审稿人独立性验证 | 检查是否有引用其他审稿人意见 | 0 跨审稿人引用 |
| 报告格式合规 | 检查报告是否包含所有必要字段 | 100% 字段完整 |

### Gate GA4: 各审稿报告 → 主编综合

| 检查项 | 方法 | 通过标准 |
|--------|------|---------|
| 审稿报告间矛盾检测 | 比对不同审稿人对同一位置的评价 | 矛盾已标记并提请主编注意 |
| 引用验证完成 | Agent V 已完成全量引用验证 | 验证报告存在 |
| 去重 | 不同审稿人发现的同一问题去重合并 | 重复率<20% |

### Gate GA5: 主编综合 → 输出

| 检查项 | 方法 | 通过标准 |
|--------|------|---------|
| 严重性分级经过综合校准 | 6个审稿人的Critical问题在主编视角下一致性 | 一致性≥70% |
| 改进建议可操作 | 每条改进建议是否具体、可验证 | 100% 可操作 |
| 优先级排序 | 改进路线图按严重性+修复成本排序 | 合理排序 |
| review-actions.json Schema | JSON Schema 验证通过 | 100% 字段符合Schema |

### Gate GA6: 输出 → 写作项目接收

| 检查项 | 方法 | 通过标准 |
|--------|------|---------|
| JSON文件结构完整性 | Schema 验证 | 通过 |
| Markdown报告可读性 | 人工快速扫读 | 结构清晰、无格式错误 |
| 文件路径正确 | 确认输出文件在约定位置 | 路径存在 |

### Gate GA7: 反馈闭环验证

| 检查项 | 方法 | 通过标准 |
|--------|------|---------|
| 修改采纳率 | 写作项目修复后统计 action 完成率 | ≥60% 采纳 |
| 误报率 | 被写作项目合理驳回的建议占比 | ≤30% |
| 遗漏率 | 修改后稿件是否出现了审稿未发现的新问题 | ≤2 new issues |

### Gate GA8: Phase结束 — 编码完整性

| 检查项 | 方法 | 通过标准 |
|--------|------|---------|
| FEATURE_LIST.md 更新 | 确认任务状态与实际完成一致 | 100% 一致 |
| SESSION_LOG 追加 | 确认本次会话所有操作已记录 | 完整 |
| metrics-raw.json 更新 | 效率数据已收集 | 数据存在 |
| git commit | 所有变更已提交 | git status clean |
| workflow-evolution.md | 如有流程改进已记录 | 已检查 |

## 关卡执行顺序

```
输入稿件
  │
  ▼
[GA1] 稿件接收检查
  │
  ▼
Agent P 预处理
  │
  ▼
[GA2] 知情包+分发检查
  │
  ▼
Agent R1-R6 并行审稿
  │
  ▼
[GA3] 各审稿人关卡复查 (Agent G)
  │
  ▼
Agent V 引用验证
  │
  ▼
[GA4] 审稿报告一致性检查
  │
  ▼
Agent M 主编综合
  │
  ▼
[GA5] 综合质量检查
  │
  ▼
Agent F 输出格式化
  │
  ▼
[GA6] 输出验收
  │
  ▼
交付写作项目
  │
  ▼ (写作项目修复后)
[GA7] 反馈闭环验证
  │
  ▼
[GA8] 编码存档
```
