# Medical Review Audit — 医学综述专业审稿系统

> **New here?** Start with [WHY.md](WHY.md) — what this does, why it's useful, and what you can build with it.

## 定位

独立的医学综述审稿项目，与写作项目形成**写审分离**架构。

- **输入**: 综述稿件 + 信息披露包
- **输出**: 结构化审稿报告 + 机器可解析改进指令
- **理念**: 外部审稿人视角，独立于写作过程的任何内部信息

## 架构

## 6维度审稿

| # | 审稿人 | 核心检查 |
|---|--------|---------|
| R1 | 方法学审稿人 | 研究设计、偏倚风险、证据等级、综述类型一致性 |
| R2 | 临床审稿人 | 临床推理深度、干预知识完整性、实践可操作性 |
| R3 | 逻辑与论证审稿人 | 论证多样性、推理链完整性、声称-证据匹配度 |
| R4 | 统计/数据审稿人 | RR→ARR/NNT翻译、效应量解读、P值陈述准确性 |
| R5 | 文献覆盖审稿人 | 引用完整性、关键论文遗漏、引用偏倚、学科盲区 |
| R6 | 结构与叙事审稿人 | 逻辑流、章节权重、叙事弧线、读者体验 |

## 快速开始

```bash
# 完整审稿
审稿

# 按需单维度
审稿 方法学
审稿 临床 统计

# 引用验证
验证

# 主编综合
综合
```
