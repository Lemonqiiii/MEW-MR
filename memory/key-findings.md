## 使用规范
1. 每个论点标注 **证据强度**: ★★★ (多项RCT/荟萃分析) / ★★ (单项RCT/多项观察性研究) / ★ (个案/专家意见)
2. 每个论点标注 **来源文献**: PMID/DOI
3. 跨文献叙事的逻辑关系用 `→` 标注
4. 矛盾证据用 ⚠️ 标注
