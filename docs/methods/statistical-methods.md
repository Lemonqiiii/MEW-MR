# 生物医学常用统计方法

## 基础概念
| 术语 | 英文 | 说明 |
|------|------|------|
| P值 | p-value | 在原假设成立下观察到当前或更极端结果的概率 |
| 置信区间 | Confidence Interval (CI) | 通常报告 95% CI |
| 效应量 | Effect Size | Cohen's d, η², OR, HR 等 |
| 统计功效 | Statistical Power | 1 - β，通常要求 ≥ 80% |
| I型错误 | Type I Error (α) | 假阳性，通常设为 0.05 |
| II型错误 | Type II Error (β) | 假阴性 |

## 常用检验方法速查

### 组间比较
| 场景 | 检验方法 |
|------|---------|
| 两组连续变量（正态） | 独立样本 t 检验 |
| 两组连续变量（非正态） | Mann-Whitney U 检验 |
| 多组连续变量（正态） | 单因素 ANOVA + 事后检验 |
| 多组连续变量（非正态） | Kruskal-Wallis 检验 |
| 二分类变量 | χ² 检验 或 Fisher 精确检验 |
| 配对数据 | 配对 t 检验 / Wilcoxon 符号秩检验 |

### 相关与回归
| 场景 | 方法 |
|------|------|
| 两连续变量相关 | Pearson (正态) / Spearman (非正态) |
| 多变量线性关系 | 多元线性回归 |
| 二分类结局 | Logistic 回归 |
| 生存数据 | Cox 比例风险模型 |
| 重复测量 | 混合效应模型 / GEE |
| 中介分析 | Baron & Kenny / Bootstrap |

### 多重检验校正
| 方法 | 说明 |
|------|------|
| Bonferroni | 最保守, α / n |
| Benjamini-Hochberg (BH) | 控制 FDR，常用 |
| Bonferroni-Holm | 比 Bonferroni 功效更高 |

## 荟萃分析专用
| 概念 | 说明 |
|------|------|
| I² 统计量 | 异质性比例: <25%低, 50%中, >75%高 |
| 固定效应模型 | 假设所有研究估计同一真实效应 |
| 随机效应模型 | 允许真实效应在研究间变异 (DerSimonian-Laird) |
| 漏斗图 | 检测发表偏倚的图形方法 |
| Egger 检验 | 漏斗图不对称性的定量检验 |
| 敏感性分析 | 逐篇排除检验 (leave-one-out) |
| GRADE | 证据质量分级: 高→中→低→极低 |

## 常见误区
1. **P > 0.05 ≠ 无差异** — 可能检验功效不足（样本量太小）
2. **P < 0.05 ≠ 有临床意义** — 大样本下微小差异也可显著
3. **亚组分析阳性 ≠ 可推广** — 需交互作用检验确认
4. **相关性 ≠ 因果** — 混淆因素可能导致虚假关联
