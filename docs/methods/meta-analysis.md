# 系统综述与荟萃分析方法指南

## PRISMA 2020 声明
系统综述和荟萃分析的首选报告项目 (Preferred Reporting Items for Systematic Reviews and Meta-Analyses)。

### PRISMA 2020 清单要点
1. **标题**: 明确标识为系统综述或荟萃分析
2. **摘要**: 结构化摘要（背景、方法、结果、讨论、资金）
3. **引言**: 理论基础与研究问题
4. **方法**:
   - 纳入/排除标准
   - 信息来源与检索策略
   - 文献筛选过程
   - 数据提取方法
   - 偏倚风险评估工具（RoB 2, ROBINS-I, QUADAS-2）
   - 效应量指标与合成方法
   - 异质性评估（I², τ²）
   - 发表偏倚评估（漏斗图, Egger检验）
5. **结果**: PRISMA 流程图、纳入研究特征、偏倚风险评估
6. **讨论**: 证据强度、局限性、外推性

## 常用工具
- **偏倚风险评估**: Cochrane RoB 2 (RCT), ROBINS-I (非随机), QUADAS-2 (诊断)
- **荟萃分析软件**: R (meta/metafor), Stata, RevMan, Comprehensive Meta-Analysis
- **文献管理**: Zotero, EndNote, Rayyan (筛选)

## 效应量类型
| 数据类型 | 效应量 | 说明 |
|---------|--------|------|
| 连续变量 | MD / SMD | 均数差 / 标准化均数差 |
| 二分类变量 | OR / RR / RD | 比值比 / 相对风险 / 风险差 |
| 生存数据 | HR | 风险比 |
| 诊断准确性 | Sensitivity, Specificity, AUC | |

## PROSPERO 注册
在开始系统综述前，建议在 PROSPERO (crd.york.ac.uk/prospero) 注册研究方案。
