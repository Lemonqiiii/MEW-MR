# 数据库覆盖目录

> 本文档定义了综述项目中所有可用的文献数据库，包括覆盖范围、访问方式、Agent 自动化能力和使用条件。
> 搜索Agent 在 Step 0（数据库需求评估）中参考本文档决定检索策略。

---

## Tier 1: 全自动检索 (Agent 可直接调用)

### PubMed / MEDLINE

| 属性 | 详情 |
|------|------|
| **覆盖范围** | 生物医学与生命科学，5,600+ 期刊，36M+ 记录 |
| **优势** | MeSH 受控词表，检索可重复性最高 |
| **盲区** | 对欧洲期刊、会议摘要、药理学文献覆盖不及 Embase |
| **访问方式** | E-utilities API (esearch, efetch, esummary) 或 WebFetch pubmed.ncbi.nlm.nih.gov |
| **速率限制** | 无 API key: 3 req/sec；有 API key: 10 req/sec |
| **导出格式** | XML, JSON (esummary), PMID 列表 |
| **Agent 自动化** | ✅ 全自动 |

### Semantic Scholar

| 属性 | 详情 |
|------|------|
| **覆盖范围** | 多学科学术文献，214M+ 论文，强调计算机科学和生物医学 |
| **优势** | 语义搜索（不依赖关键词匹配），引文图谱，AI 摘要 (TLDR)，高影响力引用计数 |
| **盲区** | 非英语文献覆盖率低，较新的预印本/灰色文献索引滞后 |
| **访问方式** | REST API (api.semanticscholar.org/graph/v1) |
| **速率限制** | 100 req / 5 min (无 API key) |
| **导出格式** | JSON |
| **Agent 自动化** | ✅ 全自动 |

### Europe PMC

| 属性 | 详情 |
|------|------|
| **覆盖范围** | 生物医学，包含 PubMed 全部 + 预印本 (bioRxiv, medRxiv) + 欧洲灰色文献 |
| **优势** | 对预印本和开放获取全文的覆盖显著优于 PubMed |
| **盲区** | 中文和其他非欧洲语言文献，部分补充索引有时滞 |
| **访问方式** | REST API (ebi.ac.uk/europepmc/webservices/rest) |
| **速率限制** | 较宽松 |
| **导出格式** | JSON, XML |
| **Agent 自动化** | ✅ 全自动 |

### ClinicalTrials.gov

| 属性 | 详情 |
|------|------|
| **覆盖范围** | 全球临床试验注册库，450K+ 研究记录 |
| **优势** | 包含已完成但未发表的试验——发表偏倚检测的必备工具 |
| **盲区** | 仅临床试验，不覆盖基础研究和观察性研究 |
| **使用条件** | 仅在综述涉及 RCT/临床试验时激活 |
| **访问方式** | ClinicalTrials.gov API v2 |
| **导出格式** | JSON |
| **Agent 自动化** | ✅ 全自动 |

## Tier 2: VPN 手动检索 (Agent 预编译检索式 + 用户执行)

### Embase (via Ovid 或 embase.com)

| 属性 | 详情 |
|------|------|
| **覆盖范围** | 生物医学，8,500+ 期刊（含 2,900+ PubMed 未索引的期刊），41M+ 记录 |
| **优势** | 药理学和毒理学文献的金标准；欧洲期刊覆盖率远超 PubMed；Emtree 词表比 MeSH 更细粒度 |
| **盲区** | 需机构订阅，非 OA；对中文文献覆盖率低 |
| **使用条件** | 综述涉及药物/生物制剂 → 高优先级；一般主题 → 中优先级 |
| **访问方式** | 医学院 VPN → Ovid Embase 或 embase.com → 粘贴检索式 → 导出 RIS |
| **Agent 自动化** | ⚠️ 半自动: Agent 预编译检索式 + 您 VPN 手动执行 |
| **检索式需转换** | MeSH → Emtree 术语映射 (Agent 可自动完成) |
| **导出** | RIS 格式 → 放入 `docs/search-results/` |

**Agent 预编译示例**:
```
Ovid Embase 检索式:
1. exp programmed death 1 ligand 1/         (Emtree term)
2. (PD-L1 or PD L1 or B7-H1 or CD274).ti,ab.
3. 1 or 2
4. exp drug resistance/
5. (resistan* or refactor* or escape*).ti,ab.
6. 4 or 5
7. 3 and 6
8. limit 7 to (yr="2020-2025" and english and (article or review))
```

### Cochrane Library (CENTRAL + CDSR)

| 属性 | 详情 |
|------|------|
| **覆盖范围** | Cochrane 系统综述 (CDSR) + CENTRAL 临床试验注册库 |
| **优势** | 系统综述和临床试验检索的金标准；CENTRAL 包含 PubMed/Embase 中未索引的试验报告 |
| **盲区** | 仅试验和综述，不覆盖基础研究 |
| **使用条件** | 综述涉及 RCT/临床试验 → 激活 |
| **访问方式** | 医学院 VPN → cochranelibrary.com → 高级检索 → 导出 RIS |
| **Agent 自动化** | ⚠️ 半自动: Agent 预编译检索式 + 您 VPN 手动执行 |

### CNKI (中国知网)

| 属性 | 详情 |
|------|------|
| **覆盖范围** | 中国学术期刊、学位论文、会议论文、年鉴、专利 |
| **优势** | 中文医学文献的最全面来源；唯一覆盖部分中国地方医学期刊的数据库 |
| **盲区** | 仅中文文献（部分有英文摘要）；摘要质量参差不齐；文献方法学报告常不完整 |
| **使用条件** | 综述涉及中国人群 / 中医药 / 亚洲流行病学 → 必需；其他 → 可选 |
| **访问方式** | 医学院 VPN → cnki.net → 专业检索 → 导出 EndNote/RIS |
| **Agent 自动化** | ⚠️ 半自动: Agent 预编译中文检索式 + 您 VPN 手动执行 |
| **检索式语言** | 中文关键词 + CNKI 专业检索语法 |
| **风险** | 中文期刊方法学质量普遍低于英文，筛选Agent 需额外标注 |

**Agent 预编译示例**:
```
CNKI 专业检索语法:
SU = ('程序性死亡配体1' + 'PD-L1' + 'PD L1' + 'B7-H1') * ('耐药' + '耐药性' + '抗药性' + '免疫逃逸')
AND YE = '2020-2025'
AND AB = 'English'
```

## 激活决策表

搜索Agent Step 0 使用以下决策表：

| 条件 | 激活的 Tier 2 数据库 |
|------|-------------------|
| 综述涉及**药物/生物制剂/药理学** | Embase (高优先级) |
| 综述涉及**RCT/临床试验** | Cochrane CENTRAL + ClinicalTrials.gov |
| 综述涉及**中国人群/亚洲流行病学** | CNKI + 万方 (必需) |
| 综述涉及**中医药/针灸/中西医结合** | CNKI + 万方 + SinoMed (必需) |
| 综述涉及**罕见病** | 灰色文献 + 预印本 (全部 Tier 1 自动) |
| 综述涉及**最新进展 (2024-2025)** | 预印本 + 会议摘要 (Europe PMC 自动覆盖) |
| 综述目的为**系统综述/荟萃分析** | Embase + Cochrane (强烈建议, 标记为如果未检索则作为局限性说明) |

## 特殊情况处理

### 如果 VPN 不可用

- Tier 2 数据库标记为未检索
- 在最终综述 Methods 中说明:"未检索 Embase/CNKI，可能遗漏相关文献"
- 评估Agent 在评估报告中标注数据库覆盖缺口
- 检索 Agent 在 Layer 3 外部金标准验证中检查已发表综述的 Embase/中文引用是否被我们的检索覆盖

### 如果某数据库检索结果为空

- Agent 自动验证检索式: 用已知应存在的论文测试检索式是否有效
- 如果检索式有效但结果为 0: 可能是该主题在该数据库中真的没有文献 → 记录为发现而非错误
- 如果检索式有问题: 修正后重新生成手动清单
