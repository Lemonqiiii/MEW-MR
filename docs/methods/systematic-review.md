# 系统综述方法论

## 系统综述 vs 叙述性综述

| 特征 | 系统综述 | 叙述性综述 |
|------|---------|----------|
| 研究问题 | 聚焦、明确 (PICO) | 广泛、概述性 |
| 检索策略 | 系统、可重复、多数据库 | 可能非系统 |
| 纳入/排除标准 | 预先定义、透明 | 可能不明确 |
| 偏倚风险评估 | 正式工具评估 | 通常不正式评估 |
| 数据合成 | 定量（荟萃分析）或定性 | 叙述性总结 |
| 可重复性 | 高 | 较低 |

## 系统综述流程 (Cochrane Handbook 指引)

### Phase 1: 准备
1. 形成研究问题 (PICO 框架)
2. 撰写研究方案 (Protocol)
3. PROSPERO 注册

### Phase 2: 检索
1. 数据库选择: PubMed/MEDLINE, Embase, Cochrane Library, Web of Science
2. 灰色文献: ClinicalTrials.gov, WHO ICTRP, 会议摘要
3. 构建检索式: MeSH 词 + 自由词 + 布尔运算符
4. 导出检索结果，去重

### Phase 3: 筛选
1. Round 1: 标题/摘要筛选 (2人独立)
2. Round 2: 全文筛选 (2人独立)
3. 分歧通过讨论或第三人仲裁解决
4. 记录排除原因

### Phase 4: 数据提取
1. 设计数据提取表格 (PICO + 方法学细节)
2. 双人独立提取
3. 联系原作者获取缺失数据

### Phase 5: 质量评估
- RCT: Cochrane RoB 2
- 非随机干预: ROBINS-I
- 诊断准确性: QUADAS-2
- 系统综述: AMSTAR 2

### Phase 6: 数据合成
1. 异质性评估
2. 选择固定效应或随机效应模型
3. 亚组分析 / 荟萃回归
4. 敏感性分析
5. 发表偏倚评估

### Phase 7: 报告
- PRISMA 2020 流程图
- 证据总结 (Summary of Findings table)
- GRADE 证据质量评级
