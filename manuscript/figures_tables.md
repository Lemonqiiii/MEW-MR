## Table 4: LUSC vs LUAD — Key Immunological Differences

| Feature | LUSC | LUAD | Implication for Therapy |
|---------|------|------|------------------------|
| **Targetable drivers** | Rare (EGFR/ALK ~0-2%) | Common (EGFR~15%, KRAS~30%, ALK~5%) | LUSC: ICI-dependent |
| **TMB** | High (smoking signature) | Variable (lower in EGFR+) | LUSC: theoretically ICI-responsive |
| **Tumor suppressors** | *TP53*(~80%), *CDKN2A*(~70%), *KEAP1*(~12%) | *TP53*(~50%), *KRAS*(~30%) | LUSC: KEAP1→ICI resistance |
| **Immune phenotype** | More excluded/desert | More variable | LUSC: CAF-targeting needed |
| **M2 macrophages** | Higher infiltration | Lower | LUSC: TAM targeting priority |
| **CAF content** | Higher (POSTN+, FAP+) | Lower | LUSC: stromal targeting |
| **Cytokine milieu** | TGF-β, IL-6 dominant | EGFR-driven programs | LUSC: TGF-β blockade |
| **EIC prevalence** | 28-36% | TBD (likely lower) | LUSC: multi-ICP blockade |
| **Ref PMID** | **40083325**, **34394068** | | |
