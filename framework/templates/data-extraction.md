## Extraction Protocol
1. **Two extractors**: Independent extraction by Reviewer 1 and Reviewer 2
2. **Reconciliation**: Compare extractions; resolve discrepancies by discussion or third reviewer
3. **Missing data**: Contact authors for missing information; document attempts
4. **Digitization**: If data only in figures, use WebPlotDigitizer or similar

## Multi-Arm Studies
- For studies with >2 arms: extract each relevant comparison separately
- Avoid double-counting the control group in meta-analysis
- Label arms clearly (e.g., "Author 2024 — Arm A vs Control")

## Unit of Analysis Issues
- **Cross-over trials**: Extract first-period data only (unless washout is adequate)
- **Cluster RCTs**: Check if analysis accounts for clustering; if not, adjust effective sample size
- **Repeated measures**: Extract at the primary time point specified in the review protocol
