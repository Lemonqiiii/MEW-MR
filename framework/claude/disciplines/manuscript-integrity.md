# Manuscript Integrity

## Single Source of Truth

- The sole source file for manuscript content is the file specified in `config.yaml` → `paths.manuscript_src`
- Word documents are generated by `scripts/gen_word.py` — that script handles formatting only, **no content**
- Any change: edit source file first → run generator → run self-check

## Figure and Table Discipline

- Figure and table numbers must be globally unique within the source file
- Deleting a figure/table = remove all body references + update Title Page declaration + renumber
- Self-check must verify simultaneously: body reference numbers, image caption text, Word captions

## Reference Reconstruction

- If incremental edits corrupt the reference section, use `scripts/rebuild_refs.py` to batch-rebuild
- After any reference count change, recalculate all derived statistics (e.g., Cochrane percentage, citation-type distribution)

## Figure Insertion Rules

- Figures and tables must be inserted at the position marked by `**Figure N.**` or `**Table N.**` in the markdown source
- Body references must appear before the marker (cite first, then insert)
- All figure/table regex patterns must handle both open and closed bold markers
